# زندگی‌یار (LifeManager)

داشبورد شخصی مدیریت زندگی — یک صفحه‌ی وب تک‌فایلی، کاملاً فارسی و راست‌به‌چپ، که همه‌چیز رو (کارها، سلامت، ورزش، تغذیه، دارو، یادآوری‌ها، دفتر خاطرات، خانواده، مالی، گالری تصاویر و مرور اسناد) در یک‌جا جمع می‌کنه.

هیچ سروری، هیچ حساب کاربری و هیچ اتصال اجباری به اینترنت لازم نیست. تمام داده‌ها فقط و فقط روی همون مرورگر و همون دستگاه ذخیره می‌شن (`localStorage` و `IndexedDB`) — چیزی به بیرون فرستاده نمی‌شه.

## اجرا

نیازی به نصب یا بیلد نیست. کافیه:

1. این پوشه رو (یا فقط فایل‌های `dashboard.html`، `css/`، `js/`) هرجا که خواستی کپی کنی — روی دیسک خودت، یه هاست ساده، GitHub Pages، هرچی.
2. فایل `dashboard.html` رو توی مرورگر باز کنی.

برای استفاده از بخش «اسناد و فایل‌ها» (که با File System Access API کار می‌کنه) به یه مرورگر مبتنی بر Chromium نیاز داری — کروم، اج، برَیو و مشابه. فایرفاکس و سافاری این API رو ندارن؛ بقیه‌ی برنامه بدون مشکل روشون کار می‌کنه.

## ساختار پروژه

```
dashboard.html          صفحه‌ی اصلی (تمام بخش‌ها داخل همین یه فایلن، با نمایش/مخفی‌شدن با جاوااسکریپت)
css/
  dashboard.css         تمام استایل‌ها
  all.min.css           آیکن‌ها (Font Awesome)
js/
  dashboard.js          کل منطق برنامه
  utils.js              کمک‌تابع‌های عمومی + لایه‌ی ذخیره‌سازی (localStorage / IndexedDB)
  Chart.min.js          نمودارها (Chart.js)
  all.min.js            آیکن‌ها (Font Awesome)
  mammoth.browser.min.js   نمایش فایل Word — فقط وقتی صفحه‌ی اسناد باز بشه لود می‌شه
  xlsx.full.min.js         نمایش فایل Excel — همینطور، فقط موقع نیاز لود می‌شه
  jszip.min.js              برای پیش‌نمایش فایل PowerPoint — همینطور
avatar/                 پیشنهاد پیش‌فرض برای ذخیره‌ی عکس پروفایل (اختیاری)
documents/              پیشنهاد پیش‌فرض برای فایل‌هایی که می‌خوای مرورشون کنی (اختیاری)
```

دو پوشه‌ی `avatar/` و `documents/` فقط برای این هستن که پیش‌فرض معقولی داشته باشی؛ کاربر می‌تونه هر پوشه‌ی دیگه‌ای رو هم برای عکس پروفایل یا مرور اسناد انتخاب کنه — انتخابشون اجباری نیست. فایل `.gitkeep` داخلشون فقط برای اینه که گیت پوشه‌ی خالی رو هم پوش کنه؛ خودِ برنامه این فایل‌های نقطه‌دار رو نادیده می‌گیره و جایی نشونشون نمی‌ده.

## بخش‌های برنامه

### داشبورد
- **خانه** — نمای کلی روز: کارت‌های آماری (دارو، هزینه‌ی هفته، آب امروز، ورزش امروز، وظایف، خواب، رویداد نزدیک)، نمودار فعالیت‌های هفته/ماه جاری، نمودار توزیع فعالیت‌ها، ویجت آب‌وهوا، ویجت قیمت بازار (ارز/طلا/سکه/رمزارز)، آخرین فعالیت‌ها و یادآوری‌های امروز.
- **برنامه روزانه** — چک‌لیست کارهای هر روز.
- **فعالیت‌ها** — ثبت و تاریخچه‌ی فعالیت‌های روزمره با دسته‌بندی.

### سلامت و رفاه
- **سلامت** — شاخص‌های سلامتی، آب مصرفی، خواب.
- **ورزش و یوگا** — ثبت جلسات ورزش با زمان شروع/پایان (مبنای محاسبه‌ی دقیقه‌ی ورزش در نمودار خانه).
- **تغذیه** — ثبت وعده‌های غذایی.
- **دارو و دکتر** — برنامه‌ی مصرف دارو و نوبت‌های پزشک.

### برنامه‌ریزی
- **یادآوری‌ها** — اعلان‌های زمان‌دار.
- **دفتر زندگی و خاطرات** — تقویم شمسی برای ثبت رویدادها و خاطرات همراه با عکس؛ کل این بخش پشت یه رمز عبور عددی (۴ تا ۱۶ رقمی) قفله. کنار دکمه‌ی «تغییر رمز این بخش» یه دکمه‌ی «قفل سریع» هم هست که همون لحظه این بخش رو می‌بنده و کاربر رو به صفحه‌ی خانه برمی‌گردونه.
- **خانواده** — اطلاعات اعضای خانواده.
- **تفریح** — برنامه‌ها و ایده‌های تفریحی.

### رسانه
- **گالری تصاویر** — عکس‌ها رو یا مستقیم از دیسک باز می‌کنی (فقط برای همون نشست، ذخیره نمی‌شه) یا با «افزودن و ذخیره در گالری» داخل مرورگر (IndexedDB) نگه می‌داری تا دفعه‌ی بعد هم باشن. این بخش کاملاً از عکس‌های «دفتر زندگی و خاطرات» جداست و بهشون دسترسی نداره.
- **اسناد و فایل‌ها** — یه پوشه از روی دیسک انتخاب می‌کنی (File System Access API) و فایل‌های Word، Excel، PowerPoint، PDF و متنی رو مستقیم از همون‌جا می‌بینی — بدون آپلود یا کپی. زیرپوشه‌ها هم با breadcrumb قابل مرورن. این بخش فقط برای **نمایشه**؛ دکمه‌ی «باز کردن در برنامه‌ی ویرایشگر» فایل رو برای ویرایش دانلود می‌کنه. نمایش PowerPoint یه پیش‌نمایش سبک از متن و عکس‌های هر اسلایده، نه رندر دقیق طرح‌بندی.

### مالی
- **هزینه‌ها** — ثبت و جمع‌بندی هزینه‌ها (پایه‌ی سری «هزینه» توی نمودار خانه).

### گزارش‌ها
- **رویدادها و بازخورد** — گزارش‌گیری و مرور رویدادهای ثبت‌شده در بازه‌های مختلف.

### تنظیمات
- پروفایل (نام، شغل/سبک زندگی، شهر، عکس پروفایل)، اسم برنامه.
- منابع داده‌ی آب‌وهوا و قیمت بازار — می‌تونی API اختصاصی خودت رو بذاری؛ اگه نذاری یا جواب نده، خودکار از سرویس‌های رایگان (Open-Meteo برای آب‌وهوا، tgju و CoinGecko برای قیمت‌ها) استفاده می‌شه.
- دسته‌بندی‌های سفارشی، حریم خصوصی، پشتیبان‌گیری (خروجی/ورودی JSON)، پاک‌کردن کامل داده‌ها، و درباره‌ی سازنده.

## ویژگی‌های عمومی
- **پخش‌کننده‌ی موزیک** وسط نوار بالا — پخش موقت از دیسک یا ذخیره‌ی دائمی در کتابخانه (IndexedDB)، با پلی‌لیست، shuffle/repeat و یادآوری آخرین آهنگ.
- **بزرگ‌نمایی عکس پروفایل** — نگه‌داشتن ماوس یا لمس روی آواتار (سایدبار/نوار بالا/تنظیمات) به مدت ۳ ثانیه، عکس رو بزرگ نشون می‌ده.
- تمام دیالوگ‌های تأیید (حذف، پاک‌کردن داده‌ها و…) به‌جای `confirm()` پیش‌فرض مرورگر، با یه کامپوننت سفارشی هم‌رنگ برنامه نمایش داده می‌شن.
- تقویم و تاریخ‌ها همه‌جا شمسی (جلالی) هستن.
- طراحی واکنش‌گراست و روی موبایل هم قابل استفاده‌ست.

## ذخیره‌سازی داده‌ها
- **`localStorage`** — تنظیمات، پروفایل، و رکوردهای متنی (کارها، فعالیت‌ها، مالی و…).
- **`IndexedDB`**:
  - `life_manager_files` — عکس‌های دفتر زندگی و خاطرات (خصوصی، جدا از بقیه).
  - `life_manager_media` — کتابخانه‌ی موزیک، گالری تصاویر ذخیره‌شده، و handleِ پوشه‌های انتخاب‌شده (آواتار/اسناد) برای مرورگرهایی که File System Access API رو پشتیبانی می‌کنن.
- «پاک‌کردن همه‌ی داده‌ها» در تنظیمات، همه‌ی موارد بالا رو (شامل عکس آواتار ذخیره‌شده، در صورت امکان) پاک می‌کنه — این عمل برگشت‌پذیر نیست.

## تکنولوژی
HTML / CSS / JavaScript خالص (بدون فریم‌ورک)، به‌علاوه‌ی چند کتابخونه‌ی سبک برای کارهای خاص: Chart.js (نمودارها)، Font Awesome (آیکن‌ها)، و برای نمایش اسناد — mammoth.js (Word)، SheetJS/xlsx (Excel) و JSZip (پیش‌نمایش PowerPoint) که هر سه فقط در لحظه‌ی نیاز لود می‌شن تا حجم اولیه‌ی صفحه سبک بمونه.
