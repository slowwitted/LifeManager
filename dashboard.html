            رویدادها و بازخورد

            گزارش یکجای وظیفه‌ها، ورزش، دارو و آب — برای هر ردیف می‌تونی بنویسی چی شد، بعد کل بازه رو چاپ کنی یا اکسل بگیری.

            تاریخ نوع عنوان جزئیات وضعیت گزارش / بازخورد

            گالری تصاویر

            عکس‌هاتو از روی دیسک باز کن؛ اگه خواستی برای همیشه توی گالری بمونن «ذخیره در گالری» رو بزن. این بخش کاملاً جدا از عکس‌های دفتر زندگی و خاطراته و بهشون دسترسی نداره.

            اسناد و فایل‌ها

            یه پوشه روی دیسک انتخاب کن؛ فایل‌های Word، Excel، PowerPoint، PDF و متنی مستقیم از همون پوشه نمایش داده می‌شن — چیزی کپی یا آپلود نمی‌شه. این بخش فقط برای نمایشه؛ برای ویرایش، فایل رو دانلود کن و توی برنامه‌ی خودش باز کن.

            تنظیمات

            پروفایل من

            عکس پروفایل توی پوشه‌ی avatar/ کنار برنامه ذخیره می‌شه (نه توی مرورگر). بعد از انتخاب عکس، «ذخیره پروفایل» رو بزن.

            دسته‌بندی‌های وظایف

            دسته‌های متناسب با کار و روزمره‌ی خودت رو بساز.

            حریم خصوصی

            همه‌چیز فقط روی همین دستگاه ذخیره می‌شه؛ بدون سرور، بدون اینترنت.

            ⚠️ اگه رمز رو فراموش کنی، تنها راه برگشت پاک‌کردن کامل داده‌هاست؛ چون سروری برای ریست‌کردن رمز وجود نداره.

            بخش‌های خصوصی

            هر بخشی رو که تیک بزنی، از منوی کناری مخفی می‌شه.

            اطلاع‌رسانی

            منابع داده‌ی آب‌وهوا و قیمت‌ها

            اگه اشتراک یه سرویس داری، آدرس API و کلیدش رو اینجا بذار تا از همون خونده بشه. خالی بذاری، از سرویس‌های رایگان پیش‌فرض (آب‌وهوا: Open-Meteo — قیمت‌ها: tgju و CoinGecko) استفاده می‌شه.

            • توی آدرس می‌تونی از {key} {city} {lat} {lon} استفاده کنی.
            • فرمت‌های پشتیبانی‌شده‌ی آب‌وهوا: OpenWeatherMap، WeatherAPI و Open-Meteo.
            • فرمت‌های پشتیبانی‌شده‌ی قیمت: tgju، BrsApi، یا لیست ساده‌ای از آیتم‌ها با فیلدهای title price change group.
            • اگه API اختصاصی جواب نده، خودکار از منبع رایگان خونده می‌شه.

            پشتیبان‌گیری

            تمام داده‌ها (شامل عکس‌های تقویم) رو اکسپورت کن یا از فایل بارگذاری کن — همین فایل رو روی مرورگر/سیستم دیگه هم می‌تونی ایمپورت کنی.

            بکاپ خودکار

            آخرین بکاپ: هنوز گرفته نشده. چون این برنامه سرور نداره، بکاپ خودکار فقط وقتی امکان‌پذیره که برنامه رو باز کنی؛ بعضی مرورگرها هم ممکنه برای دانلود خودکار اجازه بخوان.

            درباره‌ی سازنده

            یه دستیار شخصیِ کاملاً آفلاینه — بدون سرور، بدون اینترنت، همه‌چیز فقط روی همین دستگاه. برنامه‌ریزی روزانه، سلامت، ورزش، تغذیه، دارو، مالی، خانواده، تفریح، و یه دفتر خاطرات شخصی و قفل‌شده، همه توی یه‌جا.

            برای نشون‌دادن آب‌وهوای شهرت توی صفحه‌ی خانه؛ اختیاریه و بعداً از تنظیمات قابل تغییره.
            بر اساس این، چند دسته‌ی پیش‌فرض برات می‌سازیم؛ بعداً هم می‌تونی از تنظیمات عوضشون کنی.
